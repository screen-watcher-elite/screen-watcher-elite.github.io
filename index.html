🚀 How to Deploy This Portfolio on GitHub

You can deploy this portfolio to GitHub Pages in 2 minutes using either method:

Option A: As your personal root website (screen-watcher-elite.github.io)

  1. Create a new GitHub repository named: screen-watcher-elite.github.io.
  2. Push the contents of this portfolio folder to that repository: 
    cd c:\Users\Ashutosh\PSL2\portfolio
git init
git add .
git commit -m "feat: launch state-of-the-art portfolio"
git branch -M main
git remote add origin https://github.com/screen-watcher-elite/screen-watcher-elite.github.io.git
git push -u origin main
  3. Your site is instantly live at: https://screen-watcher-elite.github.io.

Option B: As a project site (/portfolio)

  1. Create a GitHub repository named portfolio.
  2. Push this folder and enable Settings → Pages → Source: Deploy from branch (main).
  3. Your site is live at: https://screen-watcher-elite.github.io/portfolio/.
